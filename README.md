# Autos Colombia – Sistema de Información del Parqueadero

Proyecto de **Ingeniería de Software** – IU Digital de Antioquia.
Desarrollo iterativo e incremental. Esta versión incluye la **Iteración 3: Gestión de Pagos y Mensualidades**.

| Iteración | Alcance                                                                                                                                                           |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1          | Ingreso/salida de Automóviles y SUVs, evidencias de daños, cálculo por permanencia                                                                             |
| 2          | Control de acceso por roles (RBAC), plano de celdas (Disponible / Ocupada / Mantenimiento), franja 6:00 a.m. – 10:00 p.m.                                        |
| 3          | Mensualidades de 30 días, liquidación ocasional, recargo por pernocta, ticket extraviado, recaudo multimedio, tirilla numerada, arqueo y apertura de talanquera |
